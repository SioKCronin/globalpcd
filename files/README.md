# Browser visualiser

The installable package is [`pcd/`](../pcd/). Import it from the repository
root after `pip install -e ".[dev]"`.

This folder keeps [`pcd_viz.html`](pcd_viz.html): time-domain RF, spectra, a
regime badge, and a passive acoustic map. Open the file in a browser. The
traces are precomputed; nothing here is a server, and nothing here is a
second copy of the classifier.

The product page is [`docs/index.html`](../docs/index.html).
