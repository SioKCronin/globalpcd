globalPCD · 0.1.1 Research only · not FDA-evaluated

Hold the sonication inside the stable window.

globalPCD listens to one receive window and reports whether cavitation is below, inside, or above stable oscillation. The therapy controller keeps the next pulse. This page is the product. The package is the instrument.

none

Below the window. No cavitation detected.

stable

Inside the window. Sustained oscillation, no collapse.

mixed

Approaching the ceiling. Both markers present.

inertial

Above the ceiling. Broadband collapse.

What crosses the boundary

A versioned PCDReading (schema 1.1.0). Regime, confidence, optional location, measured latency. no_reading means the deadline was missed or the frame failed. Hold. Do not replay the previous frame as live.

PullThe run loop calls process_frame(channel_data, trigger_timestamp) and reads the result before the next block.
SubscribeThe controller registers a callback and reacts when a reading is emitted.
Suggested mapstable continue · none below window · mixed step down · inertial stop or step down · no_reading hold. Policy stays with the platform.
Does not doChoose a pulse, program a solution, or arm high voltage. OpenLIFUTriggerClock is observe-only unless a bench passes allow_tx_start=True.

Where it stands

Synthetic, calibrated

Thresholds were fit on peak-normalized synthetic RF. They are not a claim about tissue, dose, or harm.

Waiting on a receive path

Phase 1 is one hydrophone and a DAQ. The open ask is a recording with samples, sample rate, drive frequency, and a trigger time, plus where the call sits in the run loop.

Single channel first

Array localization (GCC-PHAT, delay-and-sum, higher-order DMAS) is optional and off unless a site has element positions.

Log, then integrate

Each frame is one line on the pcd logger. The reading contract does not change. See the developer log.

from pcd import FeedbackConfig, PCDFeedbackEngine, SignalParams, generate_signal

params = SignalParams.lifu(f_drive=500e3)  # 200–650 kHz
_t, rf = generate_signal("inertial", params)
engine = PCDFeedbackEngine(
    FeedbackConfig(fs=params.fs, f_drive=params.f_drive, localize_every_n=0)
)
reading = engine.process_frame(rf, trigger_timestamp=0.0)
print(reading.status, reading.regime, reading.confidence, f"{reading.latency_ms:.2f} ms")

File ingest: python examples/hydrophone_ingest.py. A controller that only sees readings: python examples/mock_controller.py. Spectra and a map, in the browser: pcd_viz.html.

A recording has to carry

  • channel_data — one receive window, float samples. Integer WAV is scaled by the dtype full scale, not the file peak.
  • fs — sample rate in Hz. A WAV header has it. A .npy does not.
  • f_drive — therapy frequency. Subharmonic and harmonic bands are placed on it.
  • trigger_timestamp — seconds on a clock shared with the sonication, ideally the transmit edge for that window.

The partnership note is docs/PARTNERSHIP.md. Same contract for any controller that can hand over a window and take a reading back. OpenLIFU is the first platform it was written against.
